# README assets

Everything under `.github/readme/` is generated by the scripts in this
directory. Nothing is hand-drawn, so a change in the product changes the
picture on the next run instead of leaving a stale mock-up in the README.

| Script | Produces | Source of truth |
|---|---|---|
| `hero.mjs` | `hero-{dark,light}.svg` | The routing model: clients → dario → Claude plan / ChatGPT plan / API keys, with the `--pool-fallback` 429 vignette. Animated with SMIL + CSS; no script. |
| `terminal.mjs` | `quickstart-{dark,light}.svg` | `quickstart.cast.json`. The proxy banner lines are copied from `src/proxy.ts`; the login lines from `src/cli.ts`. Typed commands and line-by-line output, looping. |
| `tui.mjs` | `tui-analytics-*.svg`, `tui-accounts-*.svg` | **The real TUI.** Drives `startTuiApp()` from `dist/` through a fake TTY against a fixture proxy (same technique as `tools/tui-audit`), then renders the ANSI frame to SVG. Fixture numbers are illustrative; the layout, colours and text are whatever `src/tui/` renders today. Needs `npm run build` first. |

```bash
npm run build
npm run readme:assets        # all three
```

## Why SVG, and why it looks the same everywhere

GitHub serves README images through its camo proxy inside an `<img>`: no
external fonts, stylesheets or scripts load. So each SVG embeds the brand
face (Space Mono, Latin subset, ~16 KB per weight, SIL OFL — see
`fonts/OFL.txt`), draws box-drawing and block glyphs as vectors instead of
relying on any font to carry them, and pins monospace runs with
`textLength` so alignment survives a fallback font. Animations are SMIL
and CSS keyframes, which render inside `<img>` on GitHub; a
`prefers-reduced-motion` rule turns the CSS ones off.

Both a dark and a light variant are emitted and the README picks one with
`<picture>` + `prefers-color-scheme`, so the diagrams match the reader's
GitHub theme rather than forcing one.

## Checks

`scripts/check-readme-links.mjs` fails CI when a relative link, image or
`#anchor` in the README stops resolving. `scripts/check-readme-line-count.mjs`
fails it when the "~Nk lines" claim drifts from `src/`. Run both with
`npm run check:readme`.

## Social preview

`social.jpg` is the card GitHub shows when the repo link unfurls (Settings →
General → Social preview; there is no API for it, so it is uploaded by hand).
It is the one asset here that is *not* generated by a script: it was
illustrated by ChatGPT's image model from a written brief that mirrors the
hero's routing model, then scaled to 1280×640 and JPEG-encoded to stay under
GitHub's 1 MB cap. Same palette and copy as the hero; re-brief and re-upload
when the routing story changes.
