Two base URLs, one key, every tool

You already pay for Claude, for ChatGPT, or both, and each plan spends through its own runtime: Claude Code and the Agent SDK, the ChatGPT app and Codex CLI. The tools that want a base URL and an API key get a meter instead: per token, or a monthly credit balance that stops when it runs out, while the seat's own windows sit idle. dario is the seam: install it, log in once, point everything at it, and the seat is spent first.

Anthropic-shaped tools
export ANTHROPIC_BASE_URL=http://localhost:3456
export ANTHROPIC_API_KEY=dario
# claude, aider --model sonnet, the Anthropic SDKs
OpenAI-shaped tools
export OPENAI_BASE_URL=http://localhost:3456/v1
export OPENAI_API_KEY=dario
# Codex CLI, the OpenAI SDKs, chat/completions and Responses

Why people pick it

Routing, failover, a pool, a ledger, a guard

Failover that finishes the answer

With a --pool-fallback chain, a 429 on one plan is re-served by the other. A stream that dies mid-answer is completed on the same model first, chain or not.

Two plans and failover

Many seats, one endpoint

Per-model headroom routing, a session-sticky prompt cache and in-flight 429 failover across every seat you hold. New conversations go to the seat with the most headroom; fill-first, expiring-first and headroom-by-plan are a flag away.

The pool

Stops before it costs you

The overage guard halts the proxy the moment a response bills outside your subscription, and tells you why. Resume from the dashboard, the API or the CLI.

Guardrails

Tracks Claude Code on its own

Ten unattended watchers catch wire-shape drift and ship the fix, usually the same day. Every change is published as a feed you can subscribe to.

The most common question

Will my account get suspended?

I can't promise you won't be actioned, and I'd be skeptical of anyone who does. Only Anthropic decides how it enforces its terms. What I can do is lay out exactly how dario works, so you can weigh the risk yourself instead of taking anyone's word for it.

dario runs entirely on your machine, authenticates as you with your own Claude login, sends requests in the shape the official client sends, and reports nothing anywhere. What it adds is letting tools other than Claude Code use that subscription, and whether that falls within your plan's terms is Anthropic's call. The full answer, including the billing-split contingency dario is built for.

Trust and transparency

Small enough to read, checked in the open

0runtime dependencies. Verify with npm ls --production.
~42klines of TypeScript across 86 files, auditable in a weekend. CI fails if the line count drifts.
SLSAattested every release through GitHub Actions and Sigstore, published with OIDC: no long-lived npm token exists to leak.
3 × Node280 test files run in parallel on Node 18, 20 and 22; CodeQL on every push, ClusterFuzzLite weekly, an OpenSSF Scorecard.
127.0.0.1by default; upstream only to configured backends over HTTPS; a non-loopback bind is refused without DARIO_API_KEY.
Nonetelemetry. No analytics, no tracking, nothing phones home. Your tokens are never logged and sit 0600 on disk.
